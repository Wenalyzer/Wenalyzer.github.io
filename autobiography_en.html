Project Implementation and Technical Skills

In the course's drug image recognition project, I was responsible for the complete pipeline from DETR-based model training to deployment, participating in everything from data preparation to final production release. For model design, I implemented 5-fold cross-validation to ensure training stability and avoid the randomness of single training runs.

Container size optimization presented significant challenges. The original CUDA training environment was extremely large, and even after switching to PyTorch CPU version, it was still 4.25GB. To further reduce the deployment container size, I converted the model to ONNX format and replaced PyTorch and related heavy packages with ONNX Runtime and Pillow, ultimately reducing the container to 862MB. This process not only reduced model loading time from 1.6 seconds to 0.47 seconds but also significantly lowered deployment costs. I developed an HTTP API using FastAPI that allowed our team's LINE Bot to call the image recognition functionality, and set up GitHub Actions for automated deployment to GCP Cloud Run.

Beyond cloud deployment, I also built a personal server environment as a backup deployment platform for team projects. Using Cloudflare Tunnel, I established secure connections without opening any ports, following Zero Trust security principles. This environment not only provided a more cost-effective alternative with response times under 1 second, but also integrated GitHub self-hosted runners to support CI/CD workflows. Through these project experiences, I gained deep understanding of the complete engineering process from model development to production deployment, and developed practical skills in system optimization under resource constraints.
